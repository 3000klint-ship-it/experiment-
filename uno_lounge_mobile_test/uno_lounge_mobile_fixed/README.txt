UNO Lounge — MOBILE-FIRST TEST BUILD (FIXED)

IMPORTANT:
The previous mobile ZIP accidentally omitted server.js. This fixed build includes the server.

Linux Mint:
1. Open Terminal in this folder.
2. Run: npm install
3. Run: npm start
4. On the laptop test: http://localhost:3000
5. Find laptop IP with: hostname -I
6. On your phone, while on the same Wi-Fi, open:
   http://YOUR-LAPTOP-IP:3000

Example:
http://192.168.1.25:3000

This is a browser-based mobile-first multiplayer test, not an APK.
Playit.gg is not required for the local test yet.
